Ship your first request
in five minutes

Install the SDK, add your key, and make a call to the Web Tech API. Everything below runs locally with a test key. 

import { WebTech } from '@webtech/sdk';

const wt = new WebTech({
    apiKey: '[YOUR_API_KEY]'
});

const run = await wt.runs.create({
    project: 'my-first-project',
    input: 'Hello, Web Tech'
});

console.log(run.status);
