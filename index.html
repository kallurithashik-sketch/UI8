ABOUT THE PROJECT

Built for the Modern SaaS Experience

Modern SaaS UI Collection is a college team project created to demonstrate different user interface patterns commonly used in SaaS applications.

Each template is independently designed using HTML, CSS and JavaScript with responsive layouts, interactive components and reusable design ideas.
